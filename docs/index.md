# Цахим Засаг

> **Техникийн баримт бичиг [docs.dgov.mn](https://docs.dgov.mn/) дээр байна** —
> архитектур, API, ажиллагаа, runbook. Энэ хуудсууд нь танилцуулга.

Засгийн газрын нээлттэй суурь платформ ба түүний нэгдсэн нэвтрэлт. Хоёр
домэйн, нэг систем:

| | Юу вэ | Хаяг |
| --- | --- | --- |
| **Нээлттэй суурь платформ** | Төрийн байгууллагууд өөрсдийн үйлчилгээгээ дээр нь босгодог суурь | [open.dgov.mn](https://open.dgov.mn) |
| **Нэгдсэн нэвтрэлт** | Хэн болохыг тогтоодог цорын ганц газар | [sso.dgov.mn](https://sso.dgov.mn) |

Хоёрын хамаарал нэг чиглэлтэй: платформ хүнийг **өөрөө таихаа больсон**,
нэвтрэлтийг нэгдсэн үйлчилгээнд даатгасан. Тиймээс иргэн, албан хаагч хаана
нэвтэрсэн бэ гэдэг асуултад нэг хариулт байна, түүнийг хаана цуцлах вэ гэдэгт
ч нэг.

## Яагаад суурь платформ гэж байх ёстой вэ

Төрийн систем бүр өөрийн нэвтрэлт, өөрийн эрхийн загвар, өөрийн аудитын
бүртгэл, өөрийн олон хэлний дэмжлэг бичдэг. Тэдгээр нь тухайн системийн
онцлог биш — бүгд ижил зүйлийг арай өөрөөр, тус бүр өөр алдаатай бичсэн
хувилбарууд. Нэг нь эвдэрсэн үед бусад нь тэр тухай мэдэхгүй.

Суурь платформ гэдэг нь эдгээрийг **дахин бичихгүй** гэсэн үг:

- **Нэг танилт.** eID, ДАН, нууц үг — гурвуулаа нэг session загвар руу орно.
- **Нэг эрхийн загвар.** Байгууллага, гишүүнчлэл, роль, зөвшөөрөл — асуулга
  бүр байгууллагаараа хязгаарлагдана, аппын код үүнийг санах шаардлагагүй.
- **Нэг аудит.** Хэн юуг хэзээ өөрчилснийг эхний өдрөөс бичнэ.
- **Нэг олон хэл.** Монгол хэл эх сурвалж, дээр нь НҮБ-ын зургаан хэл.
  Орчуулга дутуу бол CI унана — хагас орчуулагдсан дэлгэц нийтлэгдэхгүй.
- **Нэг тэсвэрлэлт.** Таслуур, ачаалал хаях механизм, давхардсан хүсэлтийн
  нэгтгэл, ухарч давтах логик нь платформын хэсэг болохоос үйлчилгээ тус
  бүрийн санаа зовоох зүйл биш.

Эдгээрийн аль нь ч нэмэлт биш. Платформын цөмд байрлах тул дээр нь баригдсан
апп бүр тэднийг өвлөж авна.

## Юун дээр баригдсан бэ

[Gerege Nexus](https://github.com/gerege-systems/open-gerege-nexus) —
Apache 2.0 лицензтэй, Go хэл дээр бичигдсэн нээлттэй эхийн модульт платформ.
Модуль бүр өөрийн домэйн, миграц, эрхтэй бөгөөд бүгд нэг бинарид
компиллогдоно: модуль хоорондын дуудлага сүлжээгээр явахгүй, Go-ийн функцийн
дуудлага л болно.

Энэ байрлуулалтын код нээлттэй: [`open-dgov-mn`](https://github.com/gerege-systems/open-dgov-mn),
[`sso-dgov-mn`](https://github.com/gerege-systems/sso-dgov-mn).
